# Developer Profile

이 문서는 장기적으로 유효하고 현재 사용자와 확인된 선호만 기록한다. 이 배포본의
항목은 예시이므로 재사용 전에는 현재 사용자에게 맞게 확인·교체하거나 비워 둔다.
프로젝트별 기술과 현재 진행 상황은 `PROJECT_RULES.md`에 둔다.

## Example Preferences (replace after confirmation)

- 기본 소통 언어: 한국어
- 주요 관심 영역: Java 및 Spring Boot 기반 백엔드 개발
- AI 활용 방식: 실제 프로젝트 파일을 분석하고 기능을 작은 단위로 구현·검증
- 설명 방식:
  - 결론을 먼저 제시
  - 단계별 설명
  - 실행 가능한 코드 예제
  - 선택 이유와 실무 적용 방식 설명
- 코드 작업 방식:
  - 기존 구조와 코드를 먼저 확인
  - 불필요한 변경을 피함
  - 파일 경로와 변경 이유를 명확히 제시
  - 구현 후 빌드·테스트 등 검증 결과를 보고
- 학습 목표: 정답 복사보다 원리 이해와 실제 프로젝트 적용

## Collaboration Preferences

- 단순 질문은 간결하게 답한다.
- 복잡한 구현은 분석, 구현, 검증, 결과 순으로 진행한다.
- 애매한 사항을 무조건 추측하지 않되, 안전한 범위에서는 가정을 밝히고 진행한다.
- 보안, 호환성, 기존 기능 손상 가능성을 먼저 알린다.
- 전체 코드는 필요할 때 제공하되 기존 파일을 직접 수정할 수 있으면 변경 파일 중심으로 작업한다.

## Not Globally Fixed

다음 항목은 원본 프로필 또는 각 저장소에서 확인하기 전까지 전역 선호로 간주하지 않는다.

- Java 정확한 버전
- Spring Boot 정확한 버전
- Maven 또는 Gradle
- 운영체제와 IDE
- 데이터베이스 제품
- Flutter 사용 여부와 버전
- Lombok 사용 여부
- 아키텍처 패턴
- 테스트 프레임워크

## Update Rule

새로운 선호를 추가하려면 사용자가 직접 명시했거나 여러 작업에서 반복적으로 확인되어야
한다. 일회성 요구, 임시 일정, 종료된 오류, 특정 저장소 상태는 여기에 저장하지 않는다.
